## android-mesas

Use case: ui-mockup. Create a new Android mobile screen of BAR DO ZICO by adapting the supplied desktop UI visual reference. Image 1 is a reference for brand, palette, typography and simple labeled buttons, not a layout to squeeze into a phone. Generate ONE tall portrait 9:19 flat mobile application screenshot, full edge-to-edge UI, crisp high resolution, no physical phone, no device bezel, no perspective, no hand. Same dark navy bold text, white background, strong blue primary actions, green free/available indicators and pale orange occupied indicators. Portuguese Brazilian with correct accents. User is a bar owner unfamiliar with technology, and staff need large touch targets. Generous padding, readable large sans-serif fonts, no tiny table columns, no desktop navigation squished onto mobile, no charts, no marketing copy. NO LOGIN, no password, no e-mail field, no avatar, no logout. Top header 'BAR DO ZICO' and a clearly labeled hamburger button 'Menu'. This Menu is the entry point to the five areas Mesas, Caixa, Funcionários, Estoque, Cardápio; do NOT render all five as tiny horizontal tabs. Small connection line green dot 'Conectado ao bar'. This is a phone using Wi-Fi to talk to the computer at the bar. At bottom subtle 'Proposta visual • Dados de exemplo'. Must look like a realistic implementable accessible touchscreen interface matching the reference.

A large search field labeled 'Buscar mesa', placeholder 'Digite o número'. A large full-width dropdown labeled 'Mostrar', selected 'Todas as mesas'. Two large full-width table cards, stacked VERTICALLY, not side by side. Fit header, fields, both cards and footer clearly inside the portrait composition. All text must be easily readable as a mobile UI at arm's length. Keep only these two example cards; no bottom navigation bar, no other forms or dashboards.
