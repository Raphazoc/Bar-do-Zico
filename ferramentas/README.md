# Ferramentas de manutenção

Os arquivos para abrir o PC e o Android continuam na pasta principal `E:\Bar`.
Os comandos desta pasta funcionam a partir de qualquer local e usam o mesmo
projeto, banco e configurações.

## Rede e acesso

- **Verificar Rede.cmd:** conferir a conexão e os serviços.
- **Configurar Rede do Bar.cmd:** configurar a liberação local do Java no Windows.
- **Verificar Azure.cmd:** consultar a conta e os recursos Azure.
- **Acesso do Treinamento.cmd:** consultar o cadastro interno inicial do treinamento;
  o uso normal do sistema abre sem login.

## Cópias de segurança

- **Fazer Backup.cmd:** criar e conferir uma cópia da operação.
- **Conferir Backup.cmd:** verificar uma cópia existente.
- **Configurar Backups.cmd:** escolher a segunda pasta de cópias.
- **Ativar Backups Automaticos.cmd / Pausar Backups Automaticos.cmd:** controlar
  o agendamento já existente.

Consulte o [índice dos guias](../docs/README.md) ou o [guia de uso](../docs/COMO-USAR-NOVO-FRONT.md).
